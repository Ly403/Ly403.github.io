Projects

  • 2025.07 - 2026.03
    Controllable Image Restoration via Disentangled Stochastic Interpolants
    Project Leader, ADMIS Lab, Tongji University; advised by Associate Professor Wengen Li.
    • Proposed DiSI, which separates regression and generation components in stochastic interpolants to reconcile efficient reconstruction with realistic generation.
    • Developed a single model with inference-time control over the reconstruction–generation trade-off across deraining, denoising, super-resolution, and inpainting.
  • 2023.10 - 2024.11
    Effective Cloud Removal by an Improved Mean-Reverting Denoising Model
    Project Leader, ADMIS Lab, Tongji University; advised by Associate Professor Wengen Li.
    • Proposed EMRDM, a modular mean-reverting diffusion framework that directly transforms cloudy images into cloud-free images.
    • Designed a unified network for mono-temporal and multi-temporal inputs; first-author paper at CVPR 2025, with a released implementation.
  • 2024.02 - 2024.06

    Visiting Student, SCI Lab, Westlake University; mentored by Professor Xin Yuan.
